# Steps log

Every owner instruction and every step, dated, newest last. Log each new instruction the moment it is given (flow
stage F), before reporting. `growth owner_messages check` fails on any owner message that is not logged here.

How to read a row: **What the owner said** is their words (quote them); **What was done** is what it meant and what
happened; **Where** names the file, task or commit.

Example of one row (do not copy it as it is): `| I-1 | 2026-11-18 | "Our one button on every page is 'Get a quote'." | Recorded the CTA label in BRAND.md section 4 and in growth.json; the gate checks it (rules 32a, 33). | BRAND.md, growth.json, task T1 |`
Dates are YYYY-MM-DD. Numbers go up by one, with no gaps.

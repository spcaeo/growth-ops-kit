About these numbers

Readers come from Skald (our server logs): visits that read the page, an upper bound on people, whole verified days only. Skald calls a change clear only after 14 whole days.

Bounce = visits that landed on the page and read no other page, over Skald's rolling last 7 days; one snapshot is saved each morning, so a history builds up.

Google figures are Google Search Console's own (clicks, impressions, average position), since the date Search Console is connected (config.json). The last 2 to 3 days are provisional: Google still adds to them. Index status is Google's URL Inspection of the page.
